# TechVault — Admin Dashboard

React 19 + Vite 8 admin panel for the TechVault e-commerce platform.

See the main [README](../README.md) in the project root for full documentation.

## Quick Start

```bash
npm install
npm run dev
```

Runs on `http://localhost:5176`

## Features

- 📊 Dashboard with revenue analytics
- 📦 Product management (CRUD + image upload)
- 🛒 Order management (status updates)
- 👥 User management
- 📥 CSV export (orders & users)
