# TechVault — Customer Storefront

React 19 + Vite 8 frontend for the TechVault e-commerce platform.

See the main [README](../README.md) in the project root for full documentation.

## Quick Start

```bash
npm install
npm run dev
```

Runs on `http://localhost:5175`

## Backend

```bash
cd backend
npm install
npm run server
```

Runs on `http://localhost:5000`
